Displays

Warning: I am looking for volunteers to help me with the docs!

Section titled “Warning: I am looking for volunteers to help me with the docs!”

Displays are the primary output devices used by DirectGPU. They allow you to render graphics, text, and images within Lua.

Optionally accepts a resolutionMultiplier to control the display resolution.

Requires: DisplayID or X: number, Y: number (Currently unknown but working on it;)

createDisplay

Section titled “createDisplay”

Creates a display manually at a specific position and facing.

When passing "gui" as the x argument, a GUI display is created on the computer used and on the front texture of the computer. In this mode pixelWidth and pixelHeight control the GUI resolution, with an optional resolutionMultiplier.

Manual display creation also supports relative positions from the DirectGPU block. Passing true as the final relative argument creates the display at a block offset relative to the DirectGPU block instead of an absolute world position.

Requires: x : number, y : number, z : number, facing : string, width : number, height : number

Optional: [relative : boolean] or [scale : number, relative : boolean]

Returns: number (or nil if no display is found).

createDisplayAt

Section titled “createDisplayAt”

Creates a display manually at a specific position. This is just createDisplay but with more exact placement.

When only x, y, z are given, the display is anchored at that position. When facing, width and height are also given the full display geometry is specified. Relative offsets from the DirectGPU block are supported via the relative argument.

Requires: x : number, y : number, z : number

Optional: facing : string, width : number, height : number, [scale : number, relative : boolean]

Returns: number (or nil if no display is found).

enableDeltaMode

Section titled “enableDeltaMode”

Enables delta mode for a display.

Delta mode only sends changed regions of the framebuffer to the display, reducing network traffic for partially updated screens.

Requires: DisplayID
