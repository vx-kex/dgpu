3D Primitives

3D primitive methods allow you to render simple geometric shapes directly into a display’s 3D scene.

Before drawing 3D objects, ensure that the display camera has been configured using setupCamera.

Usage

Section titled “Usage”

clear3D

Section titled “clear3D”

Clears all 3D rendering state for the display.

Use this when resetting a 3D scene.

Requires: DisplayID

Example
Section titled “Example”

drawCube

Section titled “drawCube”

Draws a colored cube in 3D space.

Rotation values are specified in degrees:

  • rotX - rotation around the X axis
  • rotY - rotation around the Y axis
  • rotZ - rotation around the Z axis

Requires: DisplayID, position, size, rotation, and RGB color values.

drawPyramid

Section titled “drawPyramid”

Draws a colored pyramid in 3D space.

Rotation values are specified in degrees:

  • rotX - rotation around the X axis
  • rotY - rotation around the Y axis
  • rotZ - rotation around the Z axis

Requires: DisplayID, position, size, rotation, and RGB color values.

drawSphere

Section titled “drawSphere”

Draws a sphere in 3D space.

The segments parameter controls sphere detail:

  • lower values use fewer polygons and render faster
  • higher values create smoother spheres but require more rendering work

textureNameObj is used for texture-related rendering if supported.

Requires: DisplayID, position, radius, segments, RGB color values, texture object.
